# Gerenciador de Produtos

Projeto desenvolvido para fins de estudo utilizando Java e Spring Boot.

## Objetivo

Criar um sistema completo para gerenciamento de produtos com:

- Cadastro
- Edição
- Exclusão
- Busca
- Filtros
- Exportação para Excel
- Exportação para PDF

## Tecnologias

- Java
- Spring Boot
- PostgreSQL
- Bootstrap
